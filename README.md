# 📖 Overview

The **Bank Fraud Detection & Analytics** project leverages **Machine Learning, Python, SQL, and Power BI** to identify fraudulent banking transactions and uncover hidden patterns within financial data.

The project follows a complete data science workflow—from data cleaning and feature engineering to model training, evaluation, and business intelligence dashboards—helping financial institutions minimize fraud and improve decision-making.

---

# 🎯 Objectives

- Detect fraudulent banking transactions
- Analyze customer behavior
- Reduce financial losses caused by fraud
- Improve fraud detection accuracy using Machine Learning
- Build interactive dashboards for fraud monitoring
